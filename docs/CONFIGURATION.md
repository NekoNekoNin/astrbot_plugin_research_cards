# 原生插件配置

入口：AstrBot → 插件 → **资料卡与表格图** → **配置**。本版不新增独立 Web 设置页。

以 AstrBot 4.29.1 的原生配置组件核对下拉标签、滑块、条件显示与高级折叠。配置键保持兼容；保存会重载插件，正在处理的请求应先完成。

| 配置键 | 界面名称 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `enabled` | 基础 · 启用资料图 | true | 关闭时停止图像工具和自动表格转换，保留原有文字回答。 |
| `automatic_presentation` | 呈现 · AI 主动选择资料图 | true | 查阅到适合列表、参数或比较的数据时主动使用图片，无需用户指定；普通聊天继续使用文字。关闭后仅按用户明确要求制图。 |
| `theme` | 外观 · 资料图配色 | "light" | 只影响新生成的资料图，不修改 AstrBot 主题。 |
| `max_rows` | 容量 · 原始数据行数上限 | 40 | 1–60。宽表会按指标分组，文字超出单张图容量时返回错误并保留文字回答。 |
| `keep_source_links` | 来源 · 随图发送完整文字链接 | true | 图内保留来源名称；开启后同时提供可点击的完整网址。图像生成时间不会代替资料更新时间。 |
